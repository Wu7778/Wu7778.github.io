# 第一章网站：歌瑞森GRACING | 东台德润店

这是一个内衣门店产品网站，用于展示产品分类、当季主推、秒杀专区、活动福利和联系方式。管理员可管理商品与活动，也可准备朋友圈、小红书、抖音、视频号及公众号的推广文案和图片包。

## 本地预览

需要 Node.js 22.22 或更高的 22.x 版本。在项目文件夹打开终端，执行：

```powershell
node server.cjs
```

然后打开 **http://127.0.0.1:3000/**。保持终端运行；按 `Ctrl+C` 可停止这次启动的服务。本地预览无需安装额外依赖，也不要直接双击 `index.html`。

Windows 也可以双击 `启动店铺.cmd`，它会在后台启动网站并打开浏览器。

首次在新电脑上预览时，商品和活动数据为空，可通过“管理员登录”入口创建本地管理员后添加内容。产品参考图位于 `assets/`。当前电脑已有的数据保留在 `data/` 中，不随仓库上传。

## 文件位置

- `index.html`：首页；`style.css`：样式；`app.js`、`store-ui.js`：页面交互。
- `assets/`：产品参考图片、商品参考资料和图片来源记录。
- `server.cjs`：本地后台；`api/index.js`：Vercel 云端接口。
- `build.cjs`、`vercel.json`：Vercel 构建与发布配置。

## 数据与发布

管理员资料、商品运行数据、真实环境配置、令牌、日志和依赖目录不纳入 Git。`.env.example` 仅提供端口示例。仓库保留已有版本历史。

完整网站依赖 Node.js 后台；Vercel 版本还使用私有 Blob 存储。上传到 GitHub 不等于已经发布 GitHub Pages，当前版本需另做静态适配才能使用 Pages。现有网站地址：https://www.gracing.life/

推广功能提供文案和素材包，需自行前往对应平台确认发布。图片来源见 `assets/sources.json`，版权归原权利人，来源记录不代表新增授权。
