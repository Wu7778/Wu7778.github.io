# 歌瑞森GRACING | 东台德润店

## 启动与管理员

推荐双击“启动店铺.cmd”：自动在后台启动服务并打开浏览器，重复启动会复用已运行的服务。关闭浏览器或聊天不影响服务运行；重启电脑后再次双击启动。不设置开机自启。请通过 http://127.0.0.1:3000 访问，不要直接打开 index.html。启动日志位于 data/server.log。

需要 Node.js 22.22 或更高版本，无需安装依赖。也可在当前目录手动运行：

```powershell
node server.cjs
```

浏览器访问 http://127.0.0.1:3000 ，点击右上角“管理员登录”。首次使用会引导创建管理员账号，密码至少 12 位；以后使用该账号登录。升级后必须通过服务器访问，不能直接双击 HTML 使用管理功能。

目前为本机单管理员版本，仅监听 127.0.0.1。采用 scrypt 密码哈希、HttpOnly/SameSite 会话 Cookie、CSRF 校验与登录失败限流。会话最长 8 小时，重启服务器后需重新登录。若未来部署到公网，应另行配置 HTTPS、访问域名、部署密钥及备份。

## 产品与活动

- 商品：新增、搜索、修改、删除；1–9 张 JPG/PNG/WebP 图片（每张最多 2 MB）、名称、价格、尺码、颜色、类型、年份、季节、介绍、主推、秒杀。
- 图片第一张为封面，可移除后重新添加。详情支持逐张查看。
- 主推与秒杀开关分别控制首页专区；未虚构倒计时和库存。
- 活动公告及福利推送支持增删改查、图片、福利条件、起止时间和发布开关。输入与展示时间均按北京时间；首页只显示已发布且正在有效期内的内容，页面每分钟更新展示状态。
- 已填充四款品牌参考产品，真实售价、库存与活动由管理员确认后录入。旧原型的浏览器 localStorage 数据不会被删除，但也不会自动导入新数据库。
- 数据保存在 `data/store.json`；停止服务器后可备份整个 `data` 目录。商品图片保存在 JSON 中，适合本地小型原型，批量大规模运营时需迁移到数据库和对象存储。

## 产品 / 活动推广

朋友圈、小红书、抖音、视频号、公众号均可选择产品或活动，生成平台适配图文文案或短视频脚本。文案支持编辑、复制、下载。

“准备发布包”生成 ZIP，包含文案、原始商品/活动图片、发布说明。此版本没有社交平台 OAuth、官方发布 API 或第三方分发服务，**不会自动发布到平台**。解压内容包后，需在相应平台上传素材并确认发布。福利“推送”目前指首页展示和推广素材准备，不是微信私信或系统推送。

## 首页展示

当季主推和秒杀专区使用图片轮播，支持自动滚动、上一张/下一张、暂停以及手机横向滑动；鼠标悬停、键盘焦点进入或系统启用减少动态效果时停止自动滚动。点击任一图片或“查看全部”打开对应专区完整产品列表，再点商品查看详情。

当下店铺福利使用图片配文字的公告栏，显示活动说明、福利条件及起止时间；无图片时使用店铺公告占位图。

一键 AI 视频制作已取消，页面、任务轮询与生成/查询接口已移除，不再请求豆包服务。保留图文文案、短视频脚本和图片素材包；历史数据未删除。

已从 https://www.gbra.cn/ 的产品页面选择四款产品，每款保留两张图片，共八张。原始来源与本地文件对应关系见 assets/sources.json。图片版权归原权利人，来源记录不代表新增授权。

首页、轮播、商品详情与公告使用品牌图片。首次填充的商品仅为款式参考，不推断本店库存、年份、价格或真实秒杀活动；价格与年份留空，页面显示“价格咨询门店”。管理员可录入门店真实信息。当前数据已保存到 data/store.json，请备份该目录。品牌图也保存在 assets 中，可直接用于后续编辑。




## Vercel 正式网站

访问地址：https://gracing-dongtai-derun.vercel.app

云端使用 Vercel Functions 和私有 Blob 存储，商品、活动、管理员和会话持久保存。云端与本机数据相互独立；初次部署已迁移当前四款产品。图片逐张上传，单张上限 2 MB，最多 9 张。并发修改遇到冲突会提示刷新，不会静默覆盖。

首次管理员开通链接保存在 `data/线上管理入口.txt`，仅交给店主。打开该链接后点击“管理员登录”创建账号（密码至少 12 位）。普通公开链接不能创建管理员；创建成功后开通链接失效。

后续发布使用 Vercel CLI 的 `deploy --prod`。部署只上传程序和公开素材，排除 data、环境配置及本机日志；重新部署不覆盖云端数据。`npm test` 检查本地和云端权限、CRUD、会话及写入冲突。
